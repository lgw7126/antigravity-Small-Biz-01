## 🎯 기획 의도 (Planning Intention)

바쁜 카페의 피크 타임, 음료 제조 구역에서 단 1초의 지체도 긴 대기열과 서비스 품질 저하를 초래합니다. 특히 초보 바리스타나 아르바이트생들은 다음과 같은 3가지 돌발 상황에서 당황하게 됩니다.

1. **레시피 혼동**: 자주 나가지 않는 메뉴의 계량 수치나 재료 위치가 기억나지 않을 때
2. **갑작스러운 기기 고장**: 영수증 프린터 종이가 나오지 않거나, 포스기(POS)가 멈추거나, 머신 압력이 떨어졌을 때 대처법을 모를 때
3. **고객 특이사항 및 요주의 인물**: 블랙리스트 고객이 방문했거나 단골 고객의 특별한 커스텀 요구사항이 기억나지 않을 때

**"카페 1초 로컬 커닝페이퍼"**는 이러한 문제를 현장에서 **단 1초 만에 해결**하기 위해 기획되었습니다.

*   **직관적인 3대 탭 구분**: `☕ 레시피`, `🚨 업무 매뉴얼`, `👥 고객 관리` 영역을 별도 탭으로 완벽히 분리해 원하는 정보에 빠르게 도달합니다.
*   **초고속 초성/번호 검색**: 키보드로 단어를 길게 입력할 필요 없이 초성(`ㅂㄴㄹ`)이나 전화번호 뒷자리(`5678`)만 입력해도 즉각 필터링됩니다.
*   **오프라인 우선 (Local-First/PWA)**: 지하 매장이나 Wi-Fi 음영 구역 등 인터넷 연결이 불안정하거나 끊긴 상황에서도 아무런 문제 없이 작동합니다.
*   **원거리 가독성 극대화**: 카드를 탭하면 모달 창이 화면 전체에 가득 찬 큰 글씨로 단계별 가이드를 확대해 주어, 머신 옆에 기기를 거치해 두고 눈길만 주어도 바로 읽을 수 있습니다.

## 🛠️ 주요 특징 (Key Features)

*   **무서버/로컬 단일 파일 구조**: HTML, CSS, JavaScript를 단 하나의 `index.html` 파일에 통합하여 브라우저만 있으면 어디서든 즉시 실행됩니다.
*   **Progressive Web App (PWA) 지원**: `manifest.json`과 `sw.js`(Service Worker)를 연동하여 모바일이나 태블릿에서 홈 화면에 앱으로 추가하고 오프라인 상태에서도 완전한 독립 앱 형태로 실행할 수 있습니다.
*   **LocalStorage를 통한 데이터 영속성**: 브라우저 로컬 저장소를 활용해 입력한 데이터가 계속 보존됩니다.
*   **JSON 백업 및 복원**: 매장 간 데이터 공유 및 백업을 위해 데이터를 단 한 번의 클릭으로 JSON 파일로 내보내고 불러올 수 있습니다.

## 📖 사용 방법 (How to Use)

### 1. 기본 실행 및 PWA 앱 설치
*   **PC에서 실행**: 다운로드한 폴더 안의 [index.html](./index.html) 파일을 더블 클릭하여 크롬, 사파리 등의 브라우저로 실행합니다.
*   **홈 화면에 추가 (앱 설치)**: 모바일/태블릿 브라우저로 접속 시 '홈 화면에 추가' 또는 크롬의 '앱 설치' 버튼을 누르면 스마트폰 바탕화면에 바로가기 아이콘이 생겨 독립형 앱으로 바로 열 수 있습니다.

### 2. 초스피드 실시간 검색
*   **대분류 탭 선택**: 상단의 `☕ 레시피` / `🚨 업무 매뉴얼` / `👥 고객 관리` 중 하나를 터치하거나 클릭합니다.
    *   *단축키*: 키보드의 `Tab` 키를 누르면 마우스 조작 없이 탭을 순서대로 순환할 수 있습니다.
*   **검색창 입력**:
    *   **레시피**: 메뉴명의 초성 입력 (예: `ㅂㄴㄹ` ➡️ 아이스 바닐라 라떼)
    *   **매뉴얼**: 고장 증상 키워드 입력 (예: `ㅇㅅㅈ` ➡️ 영수증 프린터 매뉴얼)
    *   **고객 관리**: 고객명이나 전화번호 뒷자리 입력 (예: `5678` ➡️ 홍길동)
*   **상세 가이드 확대 (Zoom View)**: 검색된 결과 카드를 클릭하면 큰 텍스트 모달이 표시되어 거리가 멀어도 쉽게 제조법이나 대처 매뉴얼을 읽을 수 있습니다.
    *   `📋 복사하기` 버튼을 누르면 상세 내용이 클립보드에 복사되어 메신저 등에 즉시 공유할 수 있습니다.
    *   `ESC` 키를 누르면 열려 있는 모달 창이 닫히거나 검색창 입력 내용이 지워집니다.

### 3. 고객 카드 자동 등급 표시 규칙
*   **🌶️ 요주의 (블랙리스트) 고객**: 요주의 여부가 체크된 고객은 방문 횟수와 상관없이 상단에 🌶️ 뱃지가 표시되며, 카드 테두리와 배경색이 옅은 빨간색으로 경고 처리됩니다.
*   **🏅 단골 고객**: 방문 횟수가 5회 이상인 일반 고객은 자동으로 🏅 뱃지가 활성화됩니다.

### 4. 데이터 추가 / 수정 / 백업 (⚙️ 사장님 모드)
*   **관리 화면 진입**: 우측 상단의 ⚙️(톱니바퀴) 아이콘을 클릭하면 데이터 관리 패널로 전환됩니다.
*   **새 항목 추가 / 수정**:
    *   `➕ 새 항목 추가` 또는 테이블 우측의 `✏️ 수정` 버튼을 눌러 레시피, 매뉴얼, 고객 데이터를 관리할 수 있습니다.
    *   고객 관리 항목을 추가할 때는 방문 횟수와 요주의 여부를 설정할 수 있는 필드가 동적으로 나타납니다.
*   **백업 및 복구**:
    *   `📥 백업 다운로드`를 누르면 `cafe_quick_cheat_backup.json` 파일이 다운로드됩니다.
    *   다른 근무자나 새 기기에 데이터를 이식할 때는 ⚙️ 모드에서 `📤 백업 불러오기` 버튼을 눌러 다운로드해 둔 JSON 파일을 선택하기만 하면 즉시 매장 데이터가 동기화됩니다.
